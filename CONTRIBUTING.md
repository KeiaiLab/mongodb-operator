# Contributing

We welcome contributions! For the full contributing guide, see [docs/contributing.md](docs/contributing.md).

Quick start:
1. Fork the repository
2. Create a feature branch (`feat/my-feature`)
3. Run tests: `make test`
4. Submit a pull request

All contributions must agree to the [DCO](https://developercertificate.org/) via `Signed-off-by` trailer.
