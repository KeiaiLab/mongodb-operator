
MongoDB Operator has been installed successfully!

1. Check the operator is running:

   kubectl get pods -n {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "mongodb-operator.name" . }}"

2. Create a MongoDB ReplicaSet:

   cat <<EOF | kubectl apply -f -
   apiVersion: mongodb.keiailab.com/v1alpha1
   kind: MongoDB
   metadata:
     name: my-mongodb
     namespace: default
   spec:
     members: 3
     version:
       version: "{{ .Values.mongodb.version }}"
     storage:
       storageClassName: {{ .Values.mongodb.storageClassName | default "standard" }}
       size: 10Gi
     auth:
       mechanism: SCRAM-SHA-256
       adminCredentialsSecretRef:
         name: mongodb-admin
   EOF

3. Create a MongoDB Sharded Cluster:

   cat <<EOF | kubectl apply -f -
   apiVersion: mongodb.keiailab.com/v1alpha1
   kind: MongoDBSharded
   metadata:
     name: my-sharded
     namespace: default
   spec:
     version:
       version: "{{ .Values.mongodb.version }}"
     configServer:
       members: 3
       storage:
         size: 5Gi
     shards:
       count: 2
       membersPerShard: 3
       storage:
         size: 20Gi
     mongos:
       replicas: 2
   EOF

4. Check MongoDB resources:

   kubectl get mdb,mdbsh,mdbbackup -A

5. View operator logs:

   kubectl logs -n {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "mongodb-operator.name" . }}" -f

{{- if .Values.webhook.enabled }}

6. Admission webhook is ENABLED.

   - cert-manager Issuer/Certificate 자동 생성 — caBundle 은 cert-manager 의
     ca-injector annotation 으로 ValidatingWebhookConfiguration 에 자동 주입.
   - 검증 영역:
     * spec.version.version 화이트리스트 (8.0/8.2/8.3) 위반 거부.
     * spec.members 가 1 또는 odd >= 3 강제 (split-brain 방지).
     * spec.shards.count <= 64 강제 (operational limit).
     * spec.shards.membersPerShard 동일 quorum 강제.
   - failurePolicy=Fail — webhook 도달 불가 시 mongodb CR CRUD 거부 (ADR-0015).
   - 의존성 검증:
       kubectl get certificate -n {{ .Release.Namespace }} {{ include "mongodb-operator.fullname" . }}-webhook-cert
       kubectl get validatingwebhookconfiguration {{ include "mongodb-operator.fullname" . }}-validating
{{- else }}

6. Admission webhook is DISABLED (default).

   활성화하려면:
   - cert-manager 가 클러스터에 설치되어 있어야 함:
       kubectl get crd certificates.cert-manager.io
   - helm upgrade --reuse-values --set webhook.enabled=true ...
   - 활성화 시 invalid spec (e.g., members=4, version=7.0.5) 이 admission 단계에서
     거부됨 — controller status 에서 Failed 발견하기 전 즉시 reject.
{{- end }}
