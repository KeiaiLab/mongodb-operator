MongoDB Operator Helm Repository

Apache 2.0 라이선스의 Kubernetes Operator. MongoDB ReplicaSet · Sharded Cluster · Backup 자동화.

Add Repository

helm repo add mongodb-operator https://keiailab.github.io/mongodb-operator/
helm repo update

Search & Install

helm search repo mongodb-operator -l
helm install my-mongodb mongodb-operator/mongodb-operator
